# Sample HOME Menu icon for a forwarder .cia

`sample-icon-48.png` is the icon the project owner uses for the 3DS HOME Menu launcher of Psyduck Yellow: a hand-drawn cartoon, exactly 48x48 pixels, shared here by the owner as a sample for anyone building their own .cia forwarder. Tools such as CBC for YANBF and the Make-CIA batch file ask for a PNG of exactly 48x48 pixels with "icon" in its name; use this one or replace it with your own.

It is only an example image. The game patches, source and notes do not depend on it, and no ROM is included.
